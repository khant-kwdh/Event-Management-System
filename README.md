# Event-Management-System
## Project Description
A web-based Event Management System developed using PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap. The system allows users to browse events, manage bookings, and process payments.

## Features
- User Registration and Login
- Event Browsing and Booking
- Shopping Cart and Checkout
- Order and Booking Management
- Admin Dashboard
- Product and Category Management
- Payment Integration

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Installation
1. Download or clone this repository.
2. Copy the project folder into the XAMPP `htdocs` directory.
3. Start Apache and MySQL.
4. Create the MySQL database named `phpevent`.
5. Import the database SQL file (if available).
6. Configure the database connection in `config/dbcon.php`.
7. Open `http://localhost/your-project-folder/` in your browser.
